## 🔒 Zero Data Collection Policy

Unlike standard system tweakers, Tavrynexo AntiSpy operates strictly on a **Zero Data Collection architecture**:
* We do not collect, store, transmit, or share any personally identifiable information (PII).
* We do not collect device identifiers, hardware serial numbers, IP addresses, or browsing history.
* The application contains **no analytics SDKs**, advertising frameworks, tracking cookies, or diagnostic telemetry.
* All operations, calculations, and rule assessments execute strictly on your local computer.

---

## ✨ Key Features & Capabilities

* **Complete Telemetry Neutralization:** Disable Windows diagnostics tracking, Connected User Experiences and Telemetry (DiagTrack), Customer Experience Improvement Program (CEIP), and background data reporting.
* **Advertising & Profiling Lockdown:** Turn off system advertising IDs, personalized app suggestions, lock screen promotions, and cross-application activity tracking.
* **Background Services & Cortana Control:** Manage and halt non-essential diagnostic services, remote error reporting (WER), voice recognition data collection, and location tracking sensors.
* **Edge & App Privacy Hardening:** Prevent background data syncing, SmartScreen telemetry collection, and search history uploads.
* **One-Click Safe Optimization:** Apply curated, tested privacy profiles (Standard, Recommended, and Maximum Hardening) designed to protect your privacy without breaking essential Windows updates or core OS features.

## ⚙️ System Requirements & Permissions

* **Operating System:** Windows 10 or Windows 11 (PC)
* **Privileges Note:** This app requires a Windows account with **administrator privileges** to run its core privacy and security optimization features.
* **Execution Capabilities:** Requests desktop execution capabilities (`runFullTrust`) exclusively for modifying local Windows Registry keys, querying local Windows Services, and managing local scheduled tasks/firewall rules.
